## Hola, soy Henry Monsanto 👋

**Business Analyst / Project Manager de proyectos de software.** Llevo cuatro
años recogiendo requisitos, aterrizando alcance y acompañando equipos de
desarrollo. Antes de eso, más de una década en logística y operaciones.

Trabajar cada día junto a desarrolladores me despertó la curiosidad, así que
desde 2022 **estudio programación por mi cuenta, en mi tiempo libre**. Empecé
con Oracle ONE y Alura, y sigo aprendiendo construyendo proyectos de verdad:
nada enseña tanto como pelearse con el modelo de datos, la API y el despliegue.

🔗 **[Mira mi portafolio →](https://hmonsanto.github.io)**
